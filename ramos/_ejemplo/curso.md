# Ramo de ejemplo

Carpeta de muestra. Copia esta estructura para cada ramo:

```
ramos/<ramo>/
├── curso.md                ← lo genera el agente con "configurar ramo <ramo>"
├── material/               ← tu material del semestre actual (canónico)
└── material-adicional/     ← material de otra persona o de semestres anteriores
    └── 2026.1-lucas/
```
